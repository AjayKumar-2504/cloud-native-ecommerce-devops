# Cloud-Native E-Commerce Platform

Production-style cloud-native e-commerce platform built to demonstrate
modern DevOps and SRE practices.

## Architecture

The platform will eventually contain:

- User Service
- Product Service
- Order Service
- Payment Service

## DevOps Stack

- Linux
- Git
- GitHub
- Docker
- AWS
- Terraform
- Kubernetes
- Amazon EKS
- Helm
- GitHub Actions
- Argo CD
- Prometheus
- Grafana
- Trivy
- SonarQube
- AWS RDS
- Amazon ElastiCache
- AWS Secrets Manager

## Project Goals

- Infrastructure as Code
- Containerization
- CI/CD
- GitOps
- Kubernetes orchestration
- Observability
- Security
- Auto-scaling
- Disaster recovery
- Production troubleshooting
